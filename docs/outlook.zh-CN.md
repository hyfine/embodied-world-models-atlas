# 趋势判断：什么证据会让我改主意？

[English](outlook.en.md) · [入门导读](guide.zh-CN.md) · [索引](../CATALOG.md)

**2026-11-25 更新：** [WAM 前沿观察](convergence.zh-CN.md#frontier)把对齐、身体预测与推理成本的近期作者报告和本站推断分开。以下保留上一版判断的日期。

**判断时点：2026-11-23；观察窗口：未来 12–24 个月。** 下列是基于精选研究的判断，不是作者共识或性能排名。“高/中”表示对方向的定性把握，不是成功概率。

### 1 · 评测会从“像不像”转向“改动作，结果对不对”｜高

**依据。** [SIMPLER](https://arxiv.org/abs/2405.05941) 用约 1,500 回合、两类机器人上的成对仿真/实机评估来考察策略排序。它验证的是所测设置的相关性，不是“仿真成功 = 真机成功”。[DreamTrue](https://arxiv.org/abs/2610.12468) 报告，在其 AgiBot 评估中，经反馈后训练，人评交互缺陷率从 48.12% 降到 6.25%。这是**作者协议内的视频缺陷率**，不是机器人任务失败率。

**判断。** 若用模型筛选策略，最昂贵的错误可能是假阳性：模型里抓住了，真机却滑落。预计报告动作遵从度、假阳性和真机排序校准的工作会比只报画质更有说服力。**反证：** 在未见接触任务、不同操作者和多台机器人上，盲测表明单一画质指标已稳定预测真机排序，而反事实测试没有提供额外信息。

### 2 · 视频先验需要少量但对齐的动作证据｜高

**依据。** [Genie](https://arxiv.org/abs/2402.15391) 的潜动作从视频中学出；它们没有天然的米、弧度或夹爪开合单位。[V-JEPA 2](https://arxiv.org/abs/2506.09985) 先从大规模视频学习，再用约 62 小时 DROID 机器人交互训练动作条件预测器。这里的“无任务标注”不是“没有动作”，新环境零样本也不是零机器人数据。

**判断。** 相比继续只加通用视频，补齐相机—动作对齐、接触反例和失败轨迹可能更划算。**怎样检验：** 固定视频编码器、总预算与机器人外形，一组增加同分布视频，一组增加时间对齐的动作片段，测未见物体上的动作敏感度和闭环成功率。若动作无关组在多种新本体上持续打平，就应下调判断。

### 3 · 世界—动作模型会成为可选架构，而非取代所有 VLA｜中

**依据。** [DreamZero](https://arxiv.org/abs/2602.15922) 联合预测视频和动作；[GE-Act 2.0](https://arxiv.org/abs/2609.05588) 拆成视觉计划与逆动力学；[π0](https://arxiv.org/abs/2410.24164) 直接生成动作块。三个系统输出动作，但推理时付出的成本和对未来的约束不同。

**判断。** 得看未来是否真的改变动作选择。对需要绕开障碍、恢复失败的任务，未来约束可能有价值；快速、重复动作则可能更适合直接策略。**反证：** 在相同训练轨迹、相同硬件、相同动作更新频率下，去掉未来预测头既不改变扰动后的恢复率，也不改变数据效率。还应分别消融“训练时需要预测”与“推理时需要生成”，两者不能混为一谈。

### 4 · 几何和接触表示会与 RGB 互补，而不是简单取代它｜中

**依据。** [Spatial-UMI-Dream](https://arxiv.org/abs/2611.07229) 把米制深度和 RGB、动作放在一起；[Phoenix](https://arxiv.org/abs/2611.24938) 用场景结构表征做世界—动作建模，并在特定基准上后训练。更早的[视触觉抓取](https://proceedings.mlr.press/v78/calandra17a.html) 展示了 RGB 难以观察的抓取结果线索。这些工作不是在同一协议下对战。

**判断。** 传感器的价值取决于失败类型：深度可消除尺度歧义，却不一定发现滑移；触觉在接触前也帮不上忙。**反证：** 在固定计算与采集预算、相机位姿变化和接触扰动都独立留出的实验中，RGB-only 与多模态模型的差距稳定消失。还要计算标定、缺失传感器与跨硬件迁移的成本。

## 用一张“实验收据”读排行榜

| 必填项 | 为什么会改变结论 |
|---|---|
| 预测对象、动作单位、参考系、频率 | 预测好下一帧，不代表能在控制截止时间前给出有效关节指令 |
| 训练数据、同源片段/站点/机器人是否隔离 | 将同一条示范拆成训练和测试帧，会把记忆误认为泛化 |
| 环境：离线视频、模型内 rollout、独立仿真还是真机 | 训练和评测共用一个有偏差的模型，可能出现自证循环 |
| 分母、重置条件、人工接管、任务完成与部分进度 | 完成一半任务并不等于 50% 的回合成功；只保留成功录像会改变分母 |
| 每步延迟分布、执行动作块长度、失败后的恢复 | 长动作块可省计算，却可能来不及处理突然滑落 |
| 基线和不确定性 | 匹配数据与推理预算；报告试验次数、逐任务结果和置信区间，而非跨论文相减 |

**实用选择：** 入门算法先试 PushT/动作块；研究可控预测先做“同一开局、换动作”的配对测试；想用模拟替代实机，先在小样本上标定排序并检查假阳性。不要把未经独立验证的生成画面当作真机验收。
