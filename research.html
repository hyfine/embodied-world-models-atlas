01 / 03

Cover the method name. Is the action an input or an output?

Imagine asking a robot to push a cup into a blue circle. When a paper shows a clip of the cup moving, set visual quality aside. What went into the model, what came out, and who reads that output?

Proposed push → consequence
Starting from the same cup position, replace the gentle push with no push. A forward model forecasts outcomes under each condition. Without a goal and a selection rule it does not choose between them.
Goal → command
A direct policy can emit one command or a chunk and correct on the next observation. It need not first predict a cup inside the circle. A correct push does not prove an explicit simulation occurred.
Anticipated change ↔ action
A world-action model couples a predicted future state to action generation. Look for a testable future target and its relationship to commands, not a particular video backbone. The double arrow denotes coupling, not reversed physical causality.

History orients; it does not rank: PlaNet compares candidate actions before execution, Dreamer uses imagination to train a policy, and OpenVLA provides a direct action interface. Later coupled systems do not invalidate these routes. Trace the works by year →

03 / 03

What did the prediction actually buy?

Consider a harder task: holding a slippery cup. The following is a proposed experiment, not a reported result. Choose measurements first: cup position for geometry, contact force and slip for physics, and command units and timestamps for action. Without a measurable quantity it is hard to tell if a forecast is right.

  1. Does the state hold up? Occlude the cup, reveal it and measure position error versus occlusion time. Compare with carrying forward its last known position. A sharp clip can still put it in the wrong place.
  2. Does the consequence follow the intervention? Match starts within a stated tolerance, change the grip command and repeatedly measure slip. Compare predicted and measured differences, then shuffle command labels. A single successful clip supplies no comparison branch.
  3. Does the forecast change a decision in time? Compare with a tactile-threshold policy using the same sensors. Match action opportunities and deadlines; count drops, unnecessary regrips and late warnings. Correctly ranking two grips does not make a late warning useful.

Advanced: is correcting once the same as improving over time?

No. Regripping is an execution loop. Using the failure to select the next batch updates the data; changing grasp scores updates the judge; relearning the behavior updates the policy. Only correcting the predictor with measured slip updates the model itself. Audit independently across rounds and retest old cases: a policy that avoids difficult objects can make an unchanged predictor appear better.

What should I write down for the next paper?

Record the target and unit, whether action is an input or output, when the prediction is consumed, a comparable baseline, the denominator and timing budget, and the remaining untested claim. Separate the authors’ observation from the next test you propose.

01 / WM-1 When does imagination enter the decision?

PlaNet searches candidate sequences during deployment; Dreamer uses the model as a training environment. Frame fidelity is not their shared objective. Compare real interactions, search budgets and realized returns together.

02 / WM-2 What do video, features and geometry preserve?

Pixels preserve small objects but can waste compute redrawing a background. Feature distance can guide goal-image planning while missing slip. Geometry tests viewpoint consistency without guaranteeing forces. Use the same starting state with different actions.

03 / WM-6 How does a predicted future become a motor command?

Scoring candidate actions, inverting a desired transition and jointly generating states and actions are distinct interfaces. Joint output is not explicit search. Ablate future supervision during training separately from decoding futures during execution.

05 / EAI-5 Which computation has a deadline?

Language planning, chunk generation and whole-body control have different deadlines. Mean forward-pass latency is not end-to-end latency: longer chunks save compute but shorten the recovery window. Match control rate and executed prefix.

06 / EAI-7 Who judges success?

A model supplying both practice and evaluation can miss the same failure twice. Calibrate false positives, reversals in policy ranking and recovery on independent physical trials. A reward model, success detector and external evaluator are not interchangeable.

Three experimental receipts: data, evaluation, deployment

Data Scaling Laws in IL · Fig. 5. The authors report approximate power-law trends with numbers of objects, environments or environment–object pairs. Adding demonstrations while keeping diversity fixed does not show the same clear relation. The fitted curves are not universal laws for all control tasks.

SIMPLER · Fig. 3, physical PDF p. 8. Ask whether evaluation picks the wrong policy. Across the reported can, move-near and drawer comparison, average mean maximum rank violation is 0.056 for visual matching versus 0.375 for the validation-action-MSE proxy (lower is better). This is a ranking metric, not a success rate or a guarantee on another robot.

SERL · Table 2. All three setups list 20 demonstrations, but PCB insertion uses ground truth while cable routing and relocation use binary classifiers; relocation also has forward and backward policies. Before quoting training minutes, account for rewards, resets and human effort.
