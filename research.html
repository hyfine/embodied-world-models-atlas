Nine-survey audit: 15 reading directions, not 15 disjoint algorithms

First identify the axis: driving is a domain, JEPA a representation approach, CALVIN an evaluation protocol. SuSIE and DreamZero exemplify cascaded and joint coupling; neither substitutes for the other.

Survey-by-survey evidence, revisions and counterexamples · Exemplars and rationale for all 15 directions →
01 / WM-1

When does imagination enter the decision?

PlaNet searches candidate sequences during deployment; Dreamer uses the model as a training environment. Frame fidelity is not their shared objective. Compare real interactions, search budgets and realized returns together.

02 / WM-2

What do video, features and geometry preserve?

Pixels preserve small objects but can waste compute redrawing a background. Feature distance can guide goal-image planning while missing slip. Geometry tests viewpoint consistency without guaranteeing forces. Use the same starting state with different actions.

Trace the runtime path →
03 / WM-6

How does a predicted future become a motor command?

Scoring candidate actions, inverting a desired transition and jointly generating states and actions are distinct interfaces. Joint output is not explicit search. Ablate future supervision during training separately from decoding futures during execution.

Trace the runtime path →
04 / EAI-4

What transfers across bodies?

Web video can show object motion without saying whether a control is in meters or radians. Check frames, synchronization, gripper semantics and camera views; report held-out sites separately from held-out bodies.

Trace the runtime path →
05 / EAI-5

Which computation has a deadline?

Language planning, chunk generation and whole-body control have different deadlines. Mean forward-pass latency is not end-to-end latency: longer chunks save compute but shorten the recovery window. Match control rate and executed prefix.

Trace the runtime path →
06 / EAI-7

Who judges success?

A model supplying both practice and evaluation can miss the same failure twice. Calibrate false positives, reversals in policy ranking and recovery on independent physical trials. A reward model, success detector and external evaluator are not interchangeable.

Three experimental receipts: data, evaluation, deployment

Data Scaling Laws in IL · Fig. 5. The authors report approximate power-law trends with numbers of objects, environments or environment–object pairs. Adding demonstrations while keeping diversity fixed does not show the same clear relation. The fitted curves are not universal laws for all control tasks.

SIMPLER · Fig. 3, physical PDF p. 8. Ask whether evaluation picks the wrong policy. Across the reported can, move-near and drawer comparison, average mean maximum rank violation is 0.056 for visual matching versus 0.375 for the validation-action-MSE proxy (lower is better). This is a ranking metric, not a success rate or a guarantee on another robot.

SERL · Table 2. All three setups list 20 demonstrations, but PCB insertion uses ground truth while cable routing and relocation use binary classifiers; relocation also has forward and backward policies. Before quoting training minutes, account for rewards, resets and human effort.
