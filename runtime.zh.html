WM-1 / 潜动力学与基于模型的强化学习

PlaNet

文字版运行步骤
  1. 相机帧与上一动作
  2. RSSM 更新当前状态后验
  3. CEM 采样候选动作序列
  4. 逐序列想象潜状态并累计预测奖励
  5. 用高分序列迭代更新分布
  6. 规划器输出首步动作给环境

反馈与边界. 执行后以真实新图像修正状态，再规划；不将想象帧当作实际观测。

怎样验证. 六个像素控制仿真任务；图 4 分开检验搜索与数据采集。真实动力学规划是对照，不是部署输入。

WM-2 / 特征预测与对象表示

V-JEPA 2-AC

文字版运行步骤
  1. 读取真实相机图、目标图和末端状态
  2. 冻结编码器分别编码当前图与目标图
  3. CEM 提出末端动作候选

反馈与边界. 真机完成指令后重新读取画面与末端状态；抓放实验按预设时刻更换目标图。

WM-3 / 视频生成与交互模拟

Genie

文字版运行步骤
  1. 将起始图像编码为离散视觉 token
  2. 玩家选择一个隐动作码
  3. 时空动力网络按历史与动作逐轮填充下一帧 token
  4. 视觉解码器渲染画面供玩家观察
  5. 将新 token 加入历史，等待下一动作

反馈与边界. 回传的是生成世界的历史和玩家输入，不是外部传感器；训练时推断动作的网络不在游玩回路里。

怎样验证. 平台游戏消融中，像素动作输入使 ΔPSNR 从 1.33 到 1.91，而 FVD 从 38.8 变为 40.1；记忆仅 16 帧，约每秒一帧。

WM-4 / 三维场景与四维演化

WonderWorld

文字版运行步骤
  1. 从单图初始化三层场景
  2. 用户给出新相机位姿和文字
  3. 渲染已知区域并补全新图像
  4. 用旧深度约束新深度，拟合分层面元
  5. 把几何加入场景并向用户渲染

反馈与边界. 用户看结果后再选位姿；保留的是几何，不是机器人策略。

怎样验证. 单块 A6000 每扩展场景 9.5 秒，并非每帧；背面未生成。

WM-5 / 驾驶世界模型

MagicDrive

文字版运行步骤
  1. 给定路图、三维框、相机参数和文字
  2. 分别编码路图与场景、物体标记
  3. 迭代去噪并交换相邻相机特征

反馈与边界. 条件由数据或用户指定；没有驾驶策略出动作，检测器不反馈下一次观测。

怎样验证. nuScenes 纯相机 BEVFusion mAP 在 1× 训练时由 32.88 升至 35.40，2× 时只升 0.25；非驾驶安全评测。

WM-6 / 机器人世界模型与 WAM

SuSIE

文字版运行步骤
  1. 接收指令和真实相机观测
  2. 图像编辑器采样未来子目标图
  3. 低层策略据当前图与子目标预测四步动作
  4. 平均重叠预测，实机执行当前动作
  5. 回读新图，到刷新时重画子目标

反馈与边界. 低层每步使用新观测；高层每 20 步刷新，不以虚拟成功信号取代实测。

怎样验证. CALVIN ABC→D 的 100 条链中五指令全成 26%；实物每任务仅 10 次，编辑器不保证可达。

EAI-1 / 语言、可行性与规划

ReKep

文字版运行步骤
  1. 从 RGB-D 场景提出三维关键点，在图像上编号
  2. 指令与标点图输入 VLM，生成各阶段的终点约束和路径约束
  3. 读取当前点位和机械臂状态，检查是否需回退阶段
  4. 子目标求解器给出末端目标位姿，路径求解器给出到达它的运动
  5. 执行路径的一小段，由底层控制器驱动机械臂

反馈与边界. 动作后更新点位并重新求解，不是每次控制都重新询问 VLM。公开模拟器直接提供跟踪与碰撞几何，真机需另行感知。

怎样验证. 表 1：七项任务各十次，自动约束成功 31/70，人工约束 48/70。表 2 的受扰三项任务不是同一个分母；自动方案成功 8/30。

EAI-2 / 视觉语言动作基础模型

OpenVLA

文字版运行步骤
  1. 读取当前相机图像与自然语言任务
  2. 融合 DINOv2 与 SigLIP 的图块特征，映射至文本嵌入空间
  3. Llama 2 以视觉与指令为条件，逐维自回归生成动作词元
  4. 解码至区间中心，按目标数据集的分位数还原动作尺度
  5. 机器人执行一次末端运动与夹爪指令，再读取新图像

反馈与边界. 示范用于离线训练；Bridge 运行脚本在动作之间刷新观测。基础策略每次只看一张图，不预测未来图像，也不在线更新权重。

怎样验证. BridgeData V2 每策略 170 次，平均得分 70.6%，部分任务可获半分；RT-2-X 为 50.6%，但在语义泛化子集上更好。不能外推到任意新本体。

EAI-3 / 示范采集与动作策略

Universal Manipulation Interface (UMI)

文字版运行步骤
  1. 读取腕部鱼眼图像、末端位姿和夹爪开度
  2. 以图像采集时刻对齐观测历史
  3. 扩散策略生成相对当前末端的目标轨迹及开度
  4. 按执行器延迟丢弃过期目标，调度余下指令
  5. 机械臂与夹爪跟踪目标，采集新一轮观测

反馈与边界. 新观测用于下次推理；手持示范的 SLAM 与训练不在实机控制环内。

怎样验证. 投掷按物体计：延迟匹配 105/120，不匹配 69/120；并非 120 个完整任务回合。

EAI-4 / 跨本体数据与预训练

Octo

文字版运行步骤
  1. 编码语言指令或目标图像及近期机器人观测
  2. 屏蔽缺失输入，用共享 Transformer 提取读出 token
  3. 小型扩散头以读出为条件去噪动作块

EAI-5 / 足式与人形控制

Rapid Motor Adaptation (RMA)

文字版运行步骤
  1. 读取关节、机身倾角、足底接触并保存状态—动作历史
  2. 慢适应器从 50 步历史估计环境潜变量（约 10 Hz）
  3. 基础策略读取当前状态、上次动作及最近潜变量（100 Hz）
  4. 输出 12 个关节角目标，由 PD 控制器转换为力矩

反馈与边界. 每个快周期直接读新状态，不等待慢线程；没有实机摩擦真值，也不在线更新权重。

怎样验证. 15 cm 下台阶为 4/5 次成功；Table II 的三种子、多回合统计是仿真。盲感知无法提前看到落差。

EAI-6 / 导航与移动操作

OK-Robot

文字版运行步骤
  1. 准备：人工扫描带位姿的 RGB-D，建语义与障碍地图
  2. 文本检索目标物，A* 将底盘导航至接近位姿
  3. 现场 RGB-D 上用目标掩模筛选 AnyGrasp 候选，控制手臂抓取
  4. 检索放置地点，导航后按当前分割点云计算释放位置
  5. 移动手臂并松爪

反馈与边界. 抓取与放置重新观测局部场景，但预扫语义地图非持续更新；不是每次失败都自动重试的全局闭环。

怎样验证. 10 个家庭、171 次实验；原始条件 58.5%，清理/消歧后 82.4%，后者改变了测试条件。

原始来源 · §II-A–D, Figs. 2–3; §III-A–D, Figs. 4–6; §V · 展开完整精读

EAI-7 / 模拟器与评测协议

CALVIN (long-horizon language control)

文字版运行步骤
  1. 从初始场景取可行的五项任务链
  2. 当前指令和传感器观测送入策略
  3. 被测策略输出机械臂与夹爪动作
  4. 仿真器执行并返回新观测与状态
  5. 任务判据决定继续、换指令或结束计分

反馈与边界. 下一步读新观测；成功才推进指令，超时截断。评测不更新策略。

怎样验证. 1,000 条可行五项链；前缀成功率与平均链长不同，须注明训练/测试场景和传感器。这不是真机验证。

EAI-8 / 强化学习后训练

SERL (real-world online training)

文字版运行步骤
  1. 腕部图像与机器人状态
  2. actor 策略输出末端目标
  3. 底层控制器跟踪目标，真机返回新观测
  4. 任务奖励与转移写入在线回放
  5. 学习器将回放与示范混采，更新策略及价值网络

反馈与边界. 机器人持续向 actor 提供观测，异步学习器周期性回传权重。非想象 rollout；原 SERL 不要求每步人工纠正。

怎样验证. 三项 Franka 任务各测 100 次；20 条示范加在线交互对比 100 条示范的 BC，不能据此断言两者真实成本相同。
